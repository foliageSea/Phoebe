<h1 align="center">菲比语音播报</h1>
<p align="center">Phoebe Voice Announcements · DSH Desktop / Web 中文语音提醒</p>

菲比为 DSH 主会话中的**结构化提问、计划评审和正常完成一轮时的最终答复**提供语音提醒。声音可以从运行 DSH 的设备发出，也可以从打开 DSH Web 的浏览器发出。插件不会修改或代答文字回复，也不播报历史消息、子 Agent、工具进度、权限弹窗或中断的答复。

## 快速开始

1. **安装并启用插件。** 需要 DSH `0.2.2-rc.5` 或更新版本。在 Desktop 或 Web 界面，使用有插件管理权限的连接打开 **插件 → 添加插件**，粘贴 [GitHub Releases](https://github.com/foliageSea/Phoebe/releases) 中 `.tgz` 安装包的下载链接，点击 **安装 → 立即启用**。
2. **选择播报模式。** 打开 **插件 → 菲比语音播报**，在「包含的组件」中点击带右箭头的 **菲比语音播报** 行，进入 **语音播报**。插件默认关闭播报；首次使用建议选择 **仅固定提醒**，内置的三条菲比录音无需 Fish Audio 密钥或联网合成。
3. **选择播报位置并试播。** 选择 **运行 DSH 的设备** 或 **当前浏览器** 并保存，按下文完成对应设置。在主会话输入「请用 `ask_user_question` 问我更喜欢蓝色还是绿色；收到回答后告诉我选了什么」。看到问题卡片后，先等语音再回答；等 Agent 正常结束这一轮，你还会听到答复提醒。

### 命令行与本地安装

如需从命令行安装，请在 DSH Host 上使用与 Web 服务相同的用户和 `DSH_HOME`。若服务使用自定义 profile，将 `web` 换成对应名称：

```sh
dsh plugin --profile web add /absolute/path/to/phoebe-voice.tgz
```

安装后，通过原来的启动方式重启 Web 服务并刷新页面。若在插件管理界面填写本地源码目录，请先在源码目录运行 `npm ci --ignore-scripts`，并填写 **Host 可访问的绝对路径**。如果曾安装旧的本地开发版，请先停用并卸载旧版，再安装 `@foliagesea/dsh-phoebe-voice`，并确认播报模式和工作区范围。

## 播报位置

### 运行 DSH 的设备（默认）

声音从 Host 的默认音频设备输出。多个符合工作区范围的主会话共用一个播放器，切走聊天页也可能听到。远程访问时，声音不会从远程浏览器发出。

- **Linux**：安装包含 `ffplay` 的 FFmpeg（Debian / Ubuntu 可执行 `sudo apt install ffmpeg`），并确认运行 DSH 的用户可访问音频设备。
- **macOS**：可通过 Homebrew 安装 FFmpeg（`brew install ffmpeg`）。插件会检查常用安装位置。
- **Windows**：安装包含 `ffplay.exe` 的 FFmpeg。将其 `bin` 目录加入 `PATH` 后重启 DSH Host（Desktop 需完全退出后重开），或在插件配置中指定 `playerPath`，例如 `C:\ffmpeg\bin\ffplay.exe`。

### 当前浏览器

适合远程或无声卡的 Host，不需要在 Host 上安装 `ffplay`。选择此位置后 Host 不会同时播放。

1. 在 **语音播报 → 播报位置** 选择 **当前浏览器**，选一个非静音模式并保存。
2. 使用 DSH **所有者连接**打开任意主会话，点击输入框下方的 **开启浏览器播放**。每个标签页只需开启一次，即可接收配置范围内所有主会话的新提醒，包括未打开的会话。
3. 切换会话或离开聊天页不会停止播放；刷新页面或手动停止后，需要再次开启。各标签页独立排队，不补播历史。

## 播报模式与隐私

| 设置项 | 播报内容 | 文本发送范围 |
| --- | --- | --- |
| **关闭**（`off`，默认） | 不播报 | 不为播报发送文本 |
| **仅固定提醒**（`notice`） | 播放本地固定录音；缺少对应预设则跳过 | 播放时不发送会话文本 |
| **朗读简短摘句**（`brief`） | 从问题或最终答复中按本地规则摘句，播报稿最多 120 个字符；无合适摘句时播固定提醒 | Fish Audio 接收播报稿；不额外调用语言模型 |
| **菲比 AI 简述**（`summary`） | 用本轮 DSH 模型把最终答复写成一两句中文；提问仍按摘句模式播报 | DSH 模型接收本机过滤后最多 3,000 个字符的最终答复，Fish Audio 只接收播报稿 |

计划评审在非静音模式下只播固定提醒。AI 简述不发送聊天历史，不启动额外 Agent，也不调用工具；模型不可用、6 秒内无结果或输出不合格时，退回本地摘句，无合适摘句时播固定提醒。模型调用可能产生费用。过滤会跳过常见代码、命令和疑似敏感内容，但**不能保证识别所有隐私或凭据**。敏感会话请用 **仅固定提醒** 或 **关闭**。

聊天输入框下方可用 **静音 / 固定 / 摘句 / AI 简述** 快捷切换，修改的是插件全局模式，不只影响当前会话。快捷开启 AI 简述需要确认；取消或按 Esc 保持原模式。

## Fish Audio、音色与预设

- **配置密钥**：摘句、AI 简述和生成自定义音色预设需要 Fish Audio API Key。可从 [Fish Audio 开发者页面](https://fish.audio/app/developers/get-started/) 获取，在插件组件的 **Fish Audio 凭据**中填写并点击 **保存密钥**。密钥由 DSH 凭据服务保存为 `FISH_API_KEY`；页面只显示配置状态，不回显密钥，保存时也不会验证。不要把密钥发到聊天里。浏览器只从 Host 接收音频，不会收到密钥。
- **更换音色**：在 **语音播报**中保存新的音色 ID（`reference_id`），再到 **固定音频预设**为该音色生成录音；也可点击 **使用默认菲比音色**恢复内置音色。生成预设时可另选免费或付费模型，不会更改实时播报的合成模型。自定义预设存于 DSH Home 的 `cache/phoebe-voice`，按音色、模型和台词区分，已成功生成的片段不会重复请求。
- **查看余额**：配置密钥后，聊天输入框下方可查看 Fish Audio **付费 API 余额**，不显示免费额度。点击余额可刷新；聊天页可见时每两分钟自动刷新，Host 最多缓存 15 秒。关闭播报不影响余额查询。

## 配置参考

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `mode` | `off` | 播报模式：`off`、`notice`、`brief`、`summary`。 |
| `playbackTarget` | `host` | 播报位置：`host` 或 `browser`。 |
| `workspaceRoot` | `/` | 默认覆盖所有工作区（包括 Windows 的所有盘符）。也可填已有目录的绝对路径（如 `D:\Projects`），只播报该目录及其子目录的主会话。更新插件不会覆盖已有范围设置。 |
| `reference_id` | [`8e80c3dcdf894213a10b48e9b08ad8c6`](https://fish.audio/m/8e80c3dcdf894213a10b48e9b08ad8c6/)（菲比） | Fish Audio 音色 ID，保存后从下次播报起使用。 |
| `fishModel` | `s2.1-pro-free` | 实时语音合成模型，也可选择消耗 Fish Audio 额度的 `s2.1-pro`。不改变音色、固定预设使用的模型或 AI 简述使用的 DSH 模型。 |
| `playerPath` | 自动查找 | 仅 Host 播放使用，可填 `ffplay` 或 `ffplay.exe` 的绝对路径。Windows 按 Host 的 `PATH` 顺序查找；其他平台先检查常用安装路径，Linux 找不到时再查 `PATH`。 |

## 播报队列与故障排查

- **排队与取消**：提醒按到达顺序播放，不相互打断。Host 播放队列和各浏览器标签页的播放队列最多等待 8 条；队列已满时跳过新提醒。问题等待最多 12 秒，答复等待最多 20 秒。已回答或取消的问题会停止播报；仅开始新一轮不会取消上一轮已完成答复的提醒。切换模式或播报位置会清空队列。
- **动态播报失败**：准备音频时失败会尝试一次固定提醒，优先用当前音色预设，否则用内置菲比录音。已取消的播报不会回退。Host 开始接收音频后，不再受 20 秒准备限时影响（仍有 30 秒总上限）；此后断流或播放器报错不会接播固定提醒。插件不会自动重试 Fish Audio，也不把实时摘句或简述写入磁盘。
- **没有声音**：确认插件已启用、播报模式不是「关闭」、会话目录在工作区范围内。使用自定义音色时，检查固定预设或 Fish Audio 密钥。Host 播放请检查 `ffplay` 和默认输出设备；浏览器播放请确认已在当前标签页开启，且标签页未静音。升级后请刷新页面再开启。
- **浏览器一直显示连接中**：若使用反向代理，确认没有缓冲 `/api/phoebe-voice.audio` 的流式响应。
- **Host 日志**：搜索 `[phoebe-voice]`。常见错误包括 `missing-player`（找不到播放器）、`missing-preset`（缺少固定预设）、`missing-key`（缺少密钥）、`http-401`（检查密钥）、`http-402`（检查额度或切换免费模型）和 `http-429`（请求受限）。播报失败不会阻止 Agent 正常工作。

## 开发与参考

使用 Node.js 22+ 安装依赖并运行测试：

```sh
npm ci --ignore-scripts
npm test
```

[Host 入口](./index.js) 注册会话钩子和音频路由；[Web 客户端入口](./client.js) 提供设置页和聊天控制。播报、预设与余额查询在 [host/](./host/)，内置录音、翻译和测试分别位于 [audio/](./audio/)、[locale/](./locale/) 和 [test/](./test/)。Host 播放将 [Fish Audio HTTP 音频流](https://docs.fish.audio/features/realtime-streaming.md)送入 `ffplay`；浏览器播放则由 Host 收集大小受限的 MP3，经认证的音频流交给 Web Audio 播放。

台词为原创中文短句，角色资料参考[库街区图鉴](https://wiki.kurobbs.com/mc/item/1309523456688947200)和[菲比角色条目](https://wuthering.wiki/character_1506.html)。
